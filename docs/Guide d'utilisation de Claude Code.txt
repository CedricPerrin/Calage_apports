# Guide d'utilisation de Claude Code

## Première utilisation

1. Ouvrir uniquement le dossier du plugin dans VS Code.
2. Vérifier que les fichiers suivants existent :
   - CLAUDE.md
   - CHECKPOINT.md
   - .claudeignore
3. Lancer Claude Code.

---

## Avant de commencer

Toujours demander :

- Lire CLAUDE.md.
- Lire CHECKPOINT.md.
- Résumer l'état actuel du projet.

Ne jamais commencer à modifier le code sans avoir compris l'état du projet.

---

## Pendant le développement

Limiter chaque conversation à une seule tâche.

Exemples :

- Corriger un bug.
- Ajouter une fonctionnalité.
- Refactoriser un module.

Éviter de mélanger plusieurs sujets dans une même conversation.

---

## Gestion du contexte

Ne pas demander à Claude d'analyser tout le projet.

Privilégier des demandes ciblées.

Exemple :

"Analyse uniquement geometrie.py et pont_hecras.py."

---

## Gros fichiers

Ne jamais ouvrir automatiquement :

- fichiers HDF
- rasters
- résultats de simulation

Les utiliser uniquement lorsqu'ils sont nécessaires.

---

## Fin d'une tâche

Toujours demander :

- Mettre à jour CHECKPOINT.md.
- Résumer les modifications.
- Lister les fichiers modifiés.

Puis commencer une nouvelle conversation.

---

## Nouvelle conversation

Au début d'un nouveau chat :

1. Lire CLAUDE.md.
2. Lire STATUT.txt
3. Continuer le développement.

---

## Bonnes pratiques

✓ Une conversation = une tâche.

✓ Garder les réponses courtes.

✓ Éviter les analyses inutiles.

✓ Mettre à jour CHECKPOINT.md régulièrement.

✓ Créer une nouvelle conversation après chaque fonctionnalité importante.

---

## En cas de bug

Fournir :

- le message d'erreur complet ;
- la trace (stack trace) ;
- les fichiers concernés.

Ne pas envoyer tout le projet si ce n'est pas nécessaire.
